# Range Forest Office — Zira Website

## Files
- index.html — main website page
- style.css — website design and responsive layout
- script.js — mobile menu and current year

## Publish
Upload all three files to your web hosting service. Make sure `index.html` remains in the main/public website folder.

The website uses Google Fonts from fonts.googleapis.com. If you want a fully offline website, replace those fonts with local fonts.
